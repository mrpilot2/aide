# Keymap

The **Keymap** page of the Settings dialog lists the actions of the
application together with their keyboard shortcuts. Use it to look up the
current shortcut of an action, to assign your own shortcuts, or to go back to
the default ones.

Help pages name actions as they appear in the menus and on this page. The
shortcut of an action is not fixed: it depends on your platform, on the
application's defaults and on your own changes. The Keymap always shows the
shortcuts that are currently in effect.

## Open the page

1. Choose the **Settings** action. It is usually in the **File** menu.
2. In the Settings dialog, select **Keymap**.

## Read the Keymap

The Keymap is a tree with two columns:

- **Action** shows the action's name. Actions are grouped the way the menus
  are, starting with **Main Menu**. Expand a group to see its actions.
- **Shortcuts** shows every shortcut assigned to the action. An action can
  have several shortcuts, or none.

Some actions have no menu entry, for example **Context Help**. They still
appear in the Keymap, and you can assign shortcuts to them like to any other
action.

## Change a shortcut

Right-click an action, or double-click it, to open its menu:

- **Add keyboard shortcut** opens the **Add Keyboard Shortcut** dialog. Press
  the key combination you want to use and click **OK**. The new shortcut is
  added to the shortcuts the action already has.
- **Remove** followed by a shortcut removes that shortcut from the action.
  There is one entry per assigned shortcut.
- **Reset to default** restores the shortcuts the application originally
  assigned to the action. It appears only when the action's shortcuts differ
  from the defaults.

A key combination should trigger only one action. Before you add a shortcut,
check that no other action in the Keymap already uses it.

## Apply your changes

Changes take effect when you click **Apply** or **OK**. **Cancel** closes the
dialog and discards changes that you have not applied. While the page has
unapplied changes, a **Reset** link discards all of them at once.

The application remembers your shortcuts and uses them the next time it
starts.
