# Appearance

The **Appearance** page of the Settings dialog controls how the application
looks: its color theme and the font used throughout the user interface.

## Open the page

1. Choose the **Settings** action. It is usually in the **File** menu.
2. In the Settings dialog, select **Appearance & Behavior** and then
   **Appearance**.

You can also type a word such as "theme" or "font" into the search field at
the top of the Settings dialog to find the page.

## Theme

The **Theme** list sets the colors of windows, dialogs and icons.

| Theme | Effect |
|---|---|
| **System** | Follows the color scheme of your operating system. |
| **Light** | Light backgrounds with dark text. |
| **Dark** | Dark backgrounds with light text. |

The application may offer additional themes. They appear in the same list.

## Font

- **Font** selects the font family for the user interface. Only scalable fonts
  are listed.
- **Size** sets the font size in points, from 6 pt to 32 pt.

## Apply your changes

Changes take effect when you click **Apply** or **OK**. **Cancel** closes the
dialog and discards changes that you have not applied. While the page has
unapplied changes, a **Reset** link restores the values that are currently in
effect.

The application remembers your theme and font and uses them the next time it
starts.
