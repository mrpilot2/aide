# Fancy Demo Help

Welcome to the help of the demo application. The demo shows the building
blocks a desktop application gets out of the box: menus and actions, a
Settings dialog, configurable keyboard shortcuts and notifications.

## Get help where you are

- **Help Contents** in the **Help** menu opens this page.
- **Context Help** opens the help for whatever you are working in: put the
  keyboard focus there and use the Context Help shortcut. The **Keymap** page
  of the Settings dialog shows which shortcut that is on your system.
- In the Settings dialog, the **Help** button opens the help for the selected
  page. It is disabled for pages without help.

## Topics

- **Workspace**: the main window of the demo.
- **Demo settings**: the example pages of the Settings dialog.
- **Appearance**, **Keymap** and **Notifications**: the built-in pages of the
  Settings dialog.
