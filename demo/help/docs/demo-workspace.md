# Workspace

The workspace is the central area of the main window. It has two parts, side
by side:

- on the left, a short description of the demo application;
- on the right, the **Notification Log**, which lists the notifications the
  application has shown.

## Show or hide the Notification Log

Choose **Notification Log** in the **View** menu. The application remembers
your choice, and the width of both parts, for the next start.

## Try out notifications

Choose **Notifications** in the **Demo** menu. The dialog that opens sends
example notifications, which then also appear in the Notification Log. How
each kind of notification is shown is set on the **Notifications** page of
the Settings dialog.
