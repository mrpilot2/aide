# Demo settings

The **Demo Page 1** group of the Settings dialog holds example pages. They
show the kinds of input elements a settings page can use: check boxes, radio
buttons, lists, text fields, sliders, date and time fields and more.

## Open the pages

1. Choose the **Settings** action. It is usually in the **File** menu.
2. In the Settings dialog, expand **Demo Page 1** and **Demo Subpage 1**.
3. Select **Demo Subpage 1.1** or **Demo Subpage 1.2**.

## Change and keep values

Change any value on a page. **Apply** stores the changes and keeps the dialog
open; **OK** stores them and closes it; **Cancel** discards them. The values
are kept for the next start of the application.
